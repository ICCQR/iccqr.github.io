ICCQR calibration markers

Drop in your display's ICC profile to get a printable QR calibration marker. Attach it to the screen it belongs to. Scanning it opens this page with the calibration inside the link, ready to save as an .icc file.

Calibrated

Install it on the computer this display is attached to.

  • Windows: open Color Management, choose the display, add the file and set it as the default. Then tick Use Windows display calibration on the Advanced tab, or the video card curves won't load. A calibration loader such as DisplayCAL's also works.
  • macOS: copy it to ~/Library/ColorSync/Profiles and pick it in Displays settings. The video card curves load automatically.
  • Linux: add it under Settings → Color in GNOME (colord), which also loads the video card curves. Elsewhere, ArgyllCMS's dispwin -I installs it and loads the curves.

What the marker carries

Matrix/shaper profiles only: primaries, white point, adaptation matrix, luminance, tone curves and video card (vcgt) curves. Everything runs in your browser; the link's data sits after the #, which browsers never send to the server. QR encoder by Kazuhiko Arase (MIT). Text stays put while fonts load thanks to Invisible Ink.
